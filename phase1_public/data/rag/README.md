# RAG index data

The public package includes an index/data contract and a small public corpus
sample only. The full local corpus is intentionally not mirrored here because
the project used locally stored source documents and generated indices.

To reproduce a local index, obtain law text that you are permitted to use,
place extracted text under a local input directory, and run the index builder.
Preserve source title, article/section locator, hash, normative level,
jurisdiction, temporal status, and evidence role for every chunk.

Do not commit private project documents or unrestricted API outputs.
