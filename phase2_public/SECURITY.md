# Security and publication boundary

The public Phase 2 tree must not contain:

- `.env`, API keys, bearer tokens, cookies, signed URLs or private endpoints;
- personal, academic or employment application materials;
- real tender, bid, contract, permit, drawing, BIM or identity-bearing files;
- raw DeepSeek/MinerU payloads derived from real projects;
- private absolute paths, local model weights, virtual environments or caches;
- PDF/DOCX/XLSX exports derived from private projects.

Only synthetic/de-identified fixtures, source metadata, reproducible code and
aggregate evaluation are intended for publication. External services may receive
content only after explicit authorisation and the approved redaction boundary.

All generated conclusions remain decision support for a professional reviewer.
The system does not make final legal, award, rejection or disqualification decisions.
